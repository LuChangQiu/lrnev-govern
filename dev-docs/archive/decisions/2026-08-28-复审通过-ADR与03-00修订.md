## P0 实施时注意（2 条，不阻断）

1. **ADR-0003 `pendingHooks` 两处细节**：
   - `.catch()` 分支未 `pendingHooks.delete()`——失败的 hook 会留陈旧条目，下次 drain 被误标 `timed_out`；建议删除动作放 `finally`；
   - `pendingHooks` 以 `hook.name` 为键——同名 hook 并发触发会互相覆盖；建议按 run id（或 callId）键控。
2. **逃逸范围**：当前实现转义所有 `</`（比 DSH 只转义 `</system-reminder>` 更宽）——更安全但会给合法 `</xxx>` 文本加 `\` 噪声；"不破坏正常文本"测试建议补一个含 `</code>` 的用例，把该行为显式固化。
