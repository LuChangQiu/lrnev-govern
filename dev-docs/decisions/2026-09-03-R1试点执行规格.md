- **前置**: harness 放量版改造完成且审查通过（evidence 过 validator strict 0 ERROR）

## 矩阵

- 客户端：claude-code（唯一；Codex/OpenCode 后续 cell）
- SHA：sha-a（45a86e15）——env `T027_SHA=sha-a` 锁定（wrapper env 优先已实现，勿依赖指针文件）
- 场景：E-01 / E-02 / E-07（explicit 关键场景代表）× 5 clean sessions = 15
- 命令形态：`T027_SCENARIO=<id> T027_SHA=sha-a npx tsx tests/e2e/t027-baseline/harness-mvp.mjs`（在仓库根运行）

## 运行前环境（每次会话前）

1. claude auth：导出 `~/.claude/settings.json` 的 env 字段（ANTHROPIC_AUTH_TOKEN/BASE_URL/MODEL 等）到进程环境——隔离 CLAUDE_CONFIG_DIR 不继承，漏了会 "Not logged in"；
2. 工作区构建产物在 `.claude/t027-harness-workspace/run-*`（gitignore，自动清理）；
3. 指针文件 current-sha.txt 不动（env 锁定生效）；每 session 前记录实际 SHA 到 sidecar。

## 每 session 验收（全部满足才 VALID，否则重试或标注）

1. exit code ∈ {0, 1, 4} 且为**数据**（AI 行为结果）——不重试；若 exit 非预期（崩溃/超时/认证错）→ 重试（≤2 次）；
2. evidence JSON 过 `node scripts/validate-evidence-manifest.mjs <file>` **strict 0 ERROR**；
3. init 工具纯净：session JSONL init 事件无 `mcp__lrnev__`（发布版）前缀工具；
4. `mcp_version: "2025-11-25"`、`git_sha` = 45a86e15 全 40hex、`sha_label: "sha-a"`；
5. `decision_context: null` + `decision_context_sent: false`（SHA A/B 无参数，客户端未传）；
6. session 录制 JSONL 存在且非空。

## 成本与预算

- claude-code 每 session ~$0.3-0.45（实测）；15 sessions 名义 ~$5-7；
- 全程预算闸 $50（R1 只占小头）；每 session 记录 usage（JSONL 有 token 数）；累计成本超 $50 立即停止并报告；
- 429/限流：退避 ≥60s 重试（Codex gateway 教训，claude 也适用）。

## 批次与提交

- 5 sessions/场景为一批；每批完成后：证据入库提交（`chore(T-027): R1 试点 E-0X sha-a 5 sessions 证据`）；
- 3 批完成后生成 R1 汇总：每场景 5 次 action_taken/action_success 表、消费方差（布尔口径 std/mean）、异常清单（重试/ANOMALY/环境问题）、成本合计；
- R1 汇总报告 DeepSeek 复审（复审通过才扩量 R2/R3 claude 双 SHA 全量）。
